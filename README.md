# career-resume-ko

확인된 경력과 프로젝트를 근거로 한국어 이력서를 작성합니다.

## 사용 예

> 확인된 프로젝트 이력으로 경력기술서를 만들고 불확실한 기간은 표시해줘.

## Codex 설치

이 저장소 전체가 하나의 스킬 폴더입니다. 터미널에서 아래 명령을 실행합니다. 같은 이름의 폴더가 이미 있으면 덮어쓰지 않습니다.

```sh
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
git clone https://github.com/Lucas02-lab/career-resume-ko.git "${CODEX_HOME:-$HOME/.codex}/skills/career-resume-ko"
```

새 Codex 세션에서 `$career-resume-ko`을 지정하거나 위 예시처럼 요청합니다. 다른 에이전트의 설치 경로는 해당 제품의 안내를 확인하세요.
